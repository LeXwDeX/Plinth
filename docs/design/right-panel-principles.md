## 一、现状（源码事实）

### 1. 2D 时，右边有两块，规则不一样

```
┌对话 360┐┌────── 舞台 ─────────────────────────┐┌检查器 300┐
│        ││ 工具条：合并/局部重绘/去背景/转3D/换贴图││ 详情     │
│        ││┌工具┐  画布           ┌图层|历史 240┐ ││          │
│        │││ 栏 │                 │ (窄时 44)   │ ││          │
└────────┘└─────────────────────────────────────┘└──────────┘
```

| | 画布侧栏“图层 / 历史” | 检查器 |
|---|---|---|
| 在哪 | 舞台**里面**（`workspace-canvas-board.tsx:909`） | 舞台**外面**（`studio-shell.tsx:42`） |
| 宽度 | 240px；画板窄于 900px 时自动收成 44px 图标条（只收一次，`canvas-side-panel.tsx:35`） | 300px，固定 |
| 能否收起 | F7 开关，Alt+F9 开历史，没有关闭按钮 | **不能收起**（按你的要求，PR #40 已删掉收起按钮） |
| 聚焦模式 | 还在 | 藏起来 |
| 标签 | 图层、历史 | 2D 只有“详情” |

- 窗口窄于约 1560px 时，画布侧栏默认就是 44px 图标条。所以问题主要不是占地，而是**两块侧栏规则不一致**。
- `studio-store.ts` 的注释还说检查器开合存在本机，是 PR #40 删功能后留下的旧注释。
- 舞台上没有对象、但画板上画了东西或放了上传图时，画布侧栏是“发送到对话”的主要入口；工具条此时只有“导出画板”（`stage-header.tsx:89–97`）。

### 2. 3D 时，右边一块

```
┌对话 360┐┌────── 舞台 ──────────────────────┐┌检查器 300────────┐
│        ││ 工具条：截图到2D / 每个可用加工步骤 ││ 模型加工|格式|详情 │
│        ││ 一个按钮 / 比较 聚焦              ││ （默认：详情）    │
│        ││   3D 查看器  贴图/白模/线框        ││                  │
│        ││              三角面·贴图尺寸       ││                  │
└────────┘└──────────────────────────────────┘└──────────────────┘
```

- 工具条上每个**当前可用**的加工步骤一个按钮（重拓扑、重贴图、骨骼绑定、动画生成和已启用的窄格式转换；仍须满足具体来源合同）。点按钮会打开检查器“模型加工”标签，并替你勾上那一步（`studio-store.ts:90,205`）。这是 `docs/product.md` 第 49 行写定的规则。
- 检查器默认打开“详情”（`studio-store.ts:158`）。
- “格式”标签的“补齐格式”会建一个加工计划，但它的确认和继续只能在“模型加工”标签里做；格式标签只显示“已暂停，请在处理面板中查看”（`model-formats.tsx:160`，`model-processing-panel.tsx:296`）。用户要跨标签找。
- “模型加工”每一步都显示“选哪个服务”的下拉框（`model-processing-panel.tsx:321`），但每一步现在只有一个可选项。

### 3. 2D 和 3D 分不清

- 舞台工具条左端已经有类型图标 + 版本号 + 句柄（`stage-header.tsx:128–136`）。但 2D 和 3D 图标**同一个颜色**，不容易一眼分开。

## 二、原则草案

**R1 工具条是动作的入口，右侧栏是设置和信息。** [推荐]

| 区域 | 管什么 | 不放什么 |
|---|---|---|
| 舞台工具条 | **动作入口**：点了会产生新版本或换类型 | 属性、长表单 |
| 舞台内部 | **怎么看、怎么画**：2D 画笔工具栏、选中图层的浮条；3D 视图模式、面数 | 针对整个版本的动作 |
| 右侧栏 | **这个对象是什么、有哪些部件、动作要怎么设置**：图层、历史、加工设置、格式、详情 | 第二套动作按钮 |

一个工具条按钮点下去，只有两种结果：
- 直接发一轮给 Agent（转 3D、换贴图、局部重绘）。积分和批准在对话里的批准卡上。
- 打开右侧栏的设置区（3D 加工）。勾步骤、看积分、确认都在那里。

**R2 右侧只有一栏。** [推荐]
把画布的“图层 / 历史”并进右侧栏，不再在舞台里另开一块。2D 和 3D 都是三个标签：

| 类型 | 标签 1（干活用） | 标签 2 | 标签 3 |
|---|---|---|---|
| 2D 图片 | 图层 | 历史 | 详情 |
| 3D 模型 | 加工 | 格式 | 详情 |

“详情”永远在最后，两种类型字段一样排。
舞台上没有对象、但画板上有内容时，按 2D 处理：显示图层、历史；工具条显示“导出画板”“发送到对话”。

**R3 默认打开“干活用”的标签。** [推荐]
- 2D 默认“图层”。3D 默认“加工”，这和你说的“点模型，在右侧选操作”一致。
- 3D 没有任何可用加工步骤时，默认“详情”，不显示空表单。
- 每种类型记住你上次停在哪个标签（2D 一份，3D 一份），换对象不跳。

**R4 右侧栏永远展开，没有收起按钮。** [已定，Lex 2026-10-10]
- 这是你今天早些时候的明确要求，PR #40（`3970ede`）已经删掉了收起按钮、记住状态和窄屏自动收起。
- 合并后的右侧栏照此执行：不收起、不记状态、窄屏也不自动收成图标条。
- 原来画布侧栏的 F7 / Alt+F9 不再是“开关”，改成“切到图层 / 切到历史”标签。
- 聚焦模式取消（见 R17），右侧栏任何时候都在。
- 代价：窄屏下画布比现在小（现在画布侧栏在窄屏会收成 44px）。这是“右侧永远展开”的直接结果，接受。

**R4b 右侧永远只有一层。** [推荐]

| 东西 | 默认 |
|---|---|
| 右侧栏本身 | 一栏，300px，常驻展开 |
| 标签 | 同一时间只显示一个。2D 默认“图层”，3D 默认“加工”（没有可用步骤时默认“详情”） |
| 标签里的内容 | 全部平铺展开，不做折叠块，长了就滚动 |
| 临时选择（如换贴图选目标模型） | 点了才弹出，选完就关，不在右侧栏里叠一层 |
| 任务中心 | 平时收着，从顶栏打开，临时盖在右侧栏上，关掉就回来 |

切换标签是右侧栏里唯一的“开合”。任务中心是全局的，不属于当前对象，所以保持临时浮层，不算第二层。

**R5 一眼分清 2D 和 3D。** [推荐]
- 不新增标题行。用现有的舞台工具条左端（图标 + 版本号 + 句柄）做身份标记，只是 **2D 和 3D 用两种颜色**。
- 同一套图标和颜色用在所有地方：舞台工具条、版本条方块、结果卡、输入框引用芯片、右侧栏标签条。
- 规则：**3D 任务产出的图片不会成为 2D 对象**。版本号规则不变（`docs/product.md` 第 257 行）。

**R6 一个动作在“对话”和“舞台”里各最多一个入口。** [推荐]
- 对话里：结果卡（包括三视图卡，它也是结果卡）。
- 舞台里：工具条。
- 任务详情只留“下载”（结果卡 P8 已定）。
- 画布浮条和右键只放**针对选中图层**的编辑（删除、排序、裁剪、去背景等）。“转 3D”“发送到对话”针对的是整张画板，从浮条和右键里去掉。
- 版本条和全部产出里的“下载”属于批量管理，保留。

**R7 3D 加工的入口。** [待定]
- 方案 1（现状，我推荐）：工具条每步一个按钮，点了打开右侧栏“加工”并勾上那一步。工具条是入口，右侧栏是设置区，符合 R1，`docs/product.md` 第 49 行不用改。
- 方案 2：去掉工具条上的加工按钮，只在右侧栏“加工”里选。工具条更干净，但要改产品文档，用户也少了一眼看到“能做什么”的地方。

**R8 一件事的确认和进度在同一个标签里。** [推荐]
“补齐格式”的确认、进度、暂停后继续，都在“格式”标签里完成，不再让用户去“加工”找。

**R9 最高质量不给选择。** [推荐]
“加工”里每一步的“选哪个服务”下拉框去掉，由 Schema 指定最好的那一个。
当前模型和这一步不兼容时，直接写原因（取自现有的输入规则校验），不让用户自己换服务试。

> **修订（2026-10-22，#321）**：同一能力启用多个 Provider 后，「只用第一个可用服务」把已启用的能力藏了起来（例如 Rodin 结果的 Bang（Rodin 来源）、换贴图的 Hyper3D Texture）。默认仍是 Schema 顺序里最好的那一个，但改为第一个**接受当前来源**的（与 Agent 计划工具一致）；兼容服务有两个及以上时出现「服务」选择框，每项写明供应商、模型和报价；只有一个时仍不出选择框。不兼容的服务不进选择框，一个都不兼容时照旧直接写原因。

> **用户决定（2026-10-22，#321）**：「多个兼容服务的时候，优先确定用户选择的，否则最好是 agent 询问用户，最后兜底一个。」三级顺序：① 用户已经选定的服务（面板的「服务」选择框、对话里点名的服务、选择卡上的选择）；② 用户没选、兼容服务又有两个及以上时，Agent 不替用户选，而是在对话里出一张选择卡问用户；③ 用户说「随便 / 用默认」或点卡片上的「用默认」时，才兜底用 Schema 顺序里第一个兼容的服务。只有一个兼容服务时直接用它，不问。

> **用户决定（2026-10-22，#321 note 98949/98950）**：默认静默执行——用户已选的服务、生成模型、来源模型和参数直接用，不再追问；只有已选项满足不了这次请求时才问，问时写明原因和可改用的对象；不替用户换成别的模型、来源或服务后付费提交。舞台选中的模型不是这一步要付费运行的来源时（如选中 Bang 结果说「再分割一次」），工具层先要求确认。「加工」里某一步做不了时写出具体原因（大小及上限、格式、来源任务），依赖它的后续步骤一并标为做不了，不自动加上跑不了的前置步骤。用户在对话里点名的服务（或选择卡上的答复）接不了当前模型时，Agent 先说原因并问，不换成别的服务付费；工具提议的来源用户回答一次就执行（#321 第二轮）。

**R10 空状态说清楚下一步。** [推荐]
舞台上没有对象、画板也是空的：右侧栏只显示一句话，“在左边对话里说你想做什么，或把图拖到画板上”。

## 三·五、工具条统一语言（R11–R15）

### 现状：2D 时有五处放按钮

| 位置 | 按钮 |
|---|---|
| 舞台上方工具条 | 合并为新版本、局部重绘、去背景、转 3D、用这张图换贴图、发送到对话、比较、放大、聚焦、导出画板 |
| 画布左侧工具栏 | 选择、抓手、矩形选框、套索选区、吸管、缩放工具、上传图片、形状、文字、铅笔、像素画笔、橡皮、裁剪、局部重绘蒙版、吸附、撤销、重做 |
| 画布浮条（选中图片时） | 发送到对话、发送到 3D、去背景、下载、删除 |
| 画布右键菜单 | 复制、剪切、复制一份、粘贴、删除、编组、解组……、发送到对话、发送到 3D、下载 |
| 画布侧栏底部 | 导出画板、发送到对话 |

3D 时：上方工具条（截图到 2D、各加工步骤、比较、聚焦）；舞台左上是视图条（贴图、白模、线框、置灰的 UV）。

### 重复和混淆（源码事实）

1. **同一件事两个入口**：上方“局部重绘”和左侧“局部重绘蒙版”。上方按钮做的就是“选中当前图，切到蒙版工具；已有选区就直接提交”（`workspace-canvas-board.tsx:757–772`）。
2. **同一件事两个名字**：“转 3D”（上方）和“发送到 3D”（浮条、右键）；“截图到 2D”和任务详情里的“发送到 2D”。
3. **名字像，不是一回事**：上方“放大”是打开大图，左侧“缩放工具”是缩放画布。
4. **同一个图标两种意思**：

| 图标 | 意思 1 | 意思 2 |
|---|---|---|
| 画笔 | 上方“局部重绘” | 左侧“像素画笔” |
| 橡皮 | 上方、浮条“去背景” | 左侧“橡皮” |
| 图片加号 | 左侧“上传图片” | 浮条“发送到对话” |
| 下载 | 上方“导出画板” | 浮条“下载” |

5. **同一个动作两种图标**：“发送到对话”上方用对话加号，浮条用图片加号。
6. **同名不同对象**：上方“去背景”作用于当前版本的图，浮条“去背景”作用于选中的图层。
7. **没做的功能占位**：3D 视图条里有一个永远置灰的“UV”。

### 原则

**R11 三处工具各管一层。** [推荐]

| 位置 | 管什么 | 用词 |
|---|---|---|
| 舞台上方工具条 | 对作品做的事：产出新版本、换类型、导出、怎么看 | 动词：局部重绘、去背景、转 3D、导出画板 |
| 舞台左侧工具栏 | 拿在手上的工具：在画布上点、拖、画。3D 时是看模型的方式 | 名词：选择、套索、画笔、蒙版；贴图、白模、线框 |
| 浮条和右键 | 对选中图层的手工编辑 | 复制、删除、编组、下载这一层 |

2D 工具栏和 3D 视图条已经在同一个位置（舞台左上），保持。

**R12 会调用模型的按钮只在上方工具条，并且有统一标记。** [推荐]
- 局部重绘、去背景、转 3D、用这张图换贴图、3D 加工步骤，都会调用模型、可能花积分。在舞台里只放上方工具条。
- 这类按钮带同一个标记（例如“✦”），一眼分清“免费的手工工具”和“要调用模型的动作”。
- 浮条和右键里去掉“去背景”“发送到 3D”“发送到对话”。
- 上方“去背景”的对象规则：画布里选中了图层，就去选中图层的背景；没选，就去当前版本这张图的背景。按钮提示写明当前对象。这样去背景只有一个入口。

**R13 “蒙版”是工具，“局部重绘”是动作。** [推荐]
- 左侧：改名“蒙版”，和矩形选框、套索一样，只负责画出区域。
- 上方：“局部重绘”，有选区就提交；没有选区就切到蒙版工具，并提示“先画出要重绘的区域”。
- 这就是现在的行为，只是名字和图标要分开，不再两个按钮都叫“局部重绘”。

**R14 一个名字、一个图标、一个意思。** [推荐]

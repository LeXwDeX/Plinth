# Bounded Draco GLB inspection

`inspect.wasm` is an offline, stateless WASI Preview 1 validator embedded in the Go asset store. It does not convert or rewrite assets. The host supplies one exact compressed bufferView plus its glTF accessor contract over stdin. Only an eight-byte success receipt is accepted on stdout. A read-only `art_ai.scan_numeric` host import sends at most 64 KiB of decoded numeric bytes per call to the existing Go absolute-address scanner, with its bounded 4 KiB carry and identical three-pass percent/JSON/entity decoding and UTF-16 handling. The host validates the borrowed memory range, scan budget and context before accepting each chunk; it retains only the scanner carry, never the WASM memory slice. No paths, environment variables, random sources, real clocks, sockets or filesystem preopens are granted. `wazero` supplies a 1 GiB linear-memory ceiling, one concurrent instance, and termination on the shared asset inspection deadline (60 seconds from its first Draco decode). Every instance is closed after use.

Supported wire subset: Draco bitstream 2.2, triangular Edgebreaker mesh, standard or valence traversal, metadata flag zero, glTF `TRIANGLES` primitives in GLB buffer zero. Point clouds, other versions/methods, metadata, triangle strips, and external/inline glTF Draco buffers have no compressed-range exemption. Every decoded attribute must be bound exactly once by unique ID; component type, component count, normalized flag, point count, index count and declared min/max must match. All stored numeric values must be finite, and all attribute mappings and triangle indices must be in range. Both raw compressed bytes and decoded numeric bytes retain the absolute HTTP(S) check. Unclassified GLB bytes, JSON and padding retain the existing full address policy. PNG/JPEG image handling is unchanged.

Resource limits are parser safety ceilings: 64 MiB per compressed range, 10 million points/faces, 16 attributes with at most four components, 64 distinct compressed ranges. Declared decoded storage, numeric validation, host scanning and overlap rereads reserve the existing shared inspection work budget before allocation; nested assets also share the absolute Draco deadline. Header counts are checked before topology allocation. The WASM memory limit and cancellation bound malformed inputs independently of their claimed glTF counts. The byte format and these bounds are not Provider settings and do not change required output slots.

## Source and strict consumption patch

`manifest.json` pins Google Draco 1.5.7, its source archive digest, WASI SDK 34.0 and its libc/LLVM commits, and the exact checker source, patch and output digests. `strict.patch` is applied only to this isolated checker build; it does not change browser decoding.

The upstream outer `DecoderBuffer::remaining_size()` check alone is insufficient. The strict patch additionally:

- checks rANS symbol and bit terminal state **and** unread internal byte count, including active bit decoders on cleanup; detects exhausted entropy reads;
- bounds sized bit readers to their declared segment, rejects synthesized out-of-range bits, checks byte consumption and zero residual bit padding;
- propagates valence `DecodeSymbols` failure and requires every valence context's decoded symbols to be consumed;
- bounds geometry/attribute declarations before allocation, rejects unsupported prediction transforms, invalid component widths/flags and overflowing varints;
- requires the outer buffer to be fully consumed after all decoder-owned objects have completed their strict checks.

With backwards compatibility and point-cloud decoding absent from the glTF build, reachable parent-buffer advances are the checked entropy segments and standard traversal segment. Pre-2.2 topology/hole branches are excluded. Attribute prediction paths consume scalar fields, the checked symbol/bit decoders, or bounded ordinary typed reads. Any decode error/trap, output mismatch or resource failure rejects the range. No structure-only fallback or full BIN allowance is used.

## Rebuild

Obtain official WASI SDK **34.0** (the recorded arm64 macOS archive is SHA-256 verified in the manifest), CMake, Python 3, `curl`, `tar` and `patch`. Set `WASI_SDK_PATH` to the extracted SDK and optionally `CMAKE` to its executable, then run `./build.sh`. It downloads and verifies the fixed Draco archive, applies the reviewable patch, builds with the glTF subset, and checks the rebuilt WASM against the manifest **before** replacing it. The SDK and C++ compiler are build-time tools only: ordinary Go builds and runtime do not need CMake, Node, CGO or network access.

A clean SDK 34.0 rebuild has been checked byte-for-byte. Changing the toolchain/source requires reviewing the resulting binary and updating the manifest deliberately. The output includes Draco, LLVM C++/compiler runtime, and WASI libc code; the adjacent `LICENSE.*` files preserve their notices. The bundled third-party license inventory includes the upstream WASI libc multi-license notice and the licenses it names.

## Validation

`isolation_draco_test.go` uses an original, synthetic octahedron encoded with the pinned upstream library. It verifies unchanged bytes through `ValidateDeliveredFile`, `Put`, `Open`, historical `Open`, and a nested archive. `address-fixtures.json` and its reproducible `address-fixture.cc.txt` generator cover genuine compressed attributes containing percent, JSON, entity and UTF-16 absolute addresses that are absent from the raw compressed input; ordinary numeric text and protocol-relative numeric bytes remain accepted. Scanner parity tests cover the existing encoding corpus across the 64 KiB host boundary, as well as host-call byte limits, overlap budget and cancellation. Malformed fixtures cover internal rANS unread data, outer tails, truncation, metadata/unknown headers, glTF binding, finite values, overlapping images, unknown bytes, missing BIN, shared work and time limits, and WASM minimum memory rejection. The original real Rodin GLB is deliberately not checked into Git; `ART_AI_DRACO_SAMPLE=/absolute/path go test ./internal/assets/local -run TestDracoActualRodinOriginalArtifact -count=1 -v` requires its exact recorded SHA-256 and adds real decode deadline/32 MiB memory rejection checks. This test does not call a Provider or spend credits. Public Task, HTTP delivery and browser acceptance remain release-level checks.
